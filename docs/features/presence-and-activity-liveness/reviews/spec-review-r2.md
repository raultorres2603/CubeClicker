## Summary

❌ changes requested — 1 MAJOR, 3 MINOR, 3 INFO. The r1 F1–F15 dispositions are substantively fixed against the actual text: AC-3 now yields `p3` / `Player 3` in slot 1; AC-5 yields `[C, B]`; AC-15/16/17 are split with coherent travel/rejoin/tombstone timelines; AC-1/2/4 use observable frames, fake-peer `close()`, gauges, timers and later `welcome`/`join`/`rejoin`; Q-3 is decided technically and the checkpoint is Q-1/Q-2/Q-4 (Q-11 noted); the reload residual, B-retained + D/E smoke, scoped AC-10, exception-safe pagehide send, T8 greps/link check and `user-authentication` AC-25 supersession row are present. One new MAJOR remains: **AC-17 requires a tombstoned welcome seed never to be displayed again, but the plan observes the feeds and prunes only on the 250 ms interval.** A same-server `welcome` at 5001 replaces `WorldState.activity` with `[e1]`; the `ActivityFeed` renders it until the next 250 ms tick, so the "does not display it again / world feed stays empty" assertion fails at 5001. The fix is a synchronous prune/filter after `observe` on every reduction (or at least on every `welcome`/`worldEntered`) before publishing, with the immediate-feed test pinned. Three MINORs cover the weakened r1 F4 timer/ring evidence, AC-2's counter observation, and the `Assumptions` "transport sends `leave`" wording; three INFOs note the AC-25 row citation, the resolved status caveat, and the T8 link-check's fragility. The spec is otherwise buildable.
