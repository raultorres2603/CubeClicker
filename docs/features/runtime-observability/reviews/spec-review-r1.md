# Spec Review — r1

## Summary

❌ changes requested — 5 BLOCKER, 3 MAJOR, 5 MINOR, 2 INFO. The design direction is sound and stays inside the containerization contract (no new service/port/route, internal-only `/metrics`, strict label allow-lists, opt-in dev overlay), but the spec/plan has acceptance-level contradictions that will fail during the build: the redaction test cannot pass with the listed paths (top-level `email` is not covered), AC-18 forbids the `le` label that AC-6's histograms must emit, the smoke's `servers_active >= 1` is measured after the multiplayer registry is drained, the planned `app.log` hub sink silently drops the structured fields through Pino, and T3/T4 are not actually parallel-safe. The minimum fixes are all in-place wording/contract changes; no architecture change is needed.

## Minimum revisions (blocking)

2. **F2** — Make AC-18/AC-7 allow the reserved histogram `le` label (and its bucket values), or explicitly scope the parser to catalog labels and skip `le`; keep AC-6's Prometheus format.
3. **F3** — Pin the AC-9 `/metrics` scrape to a point where a multiplayer client is still joined (inside `checkMultiplayerFlow` before cleanup, or a dedicated join), or assert `servers_active` 0 after the settle plus a separate joined-state scrape; update AC-9 and T3.
4. **F4** — Replace the direct `app.log` hub sink with an adapter or change `HubDeps.log` to Pino's `(fields, event)` order; align `plan.md:94-97`/`tasks.md:41` with `installShutdownHandlers`'s log order.
5. **F5** — Serialize T3/T4 (`[seq]`) or make the parallel batch safe (workspace-scoped lint/typecheck, no T3 smoke/frontend-prod build before T4 finishes); update `[P]`, verify commands and the graph.
6. **F6** — Unify the renderer adapter `stats()` shape (`{ calls, triangles }` with session mapping to `drawCalls`, or `{ drawCalls }`) across AC-21, plan and T4.
7. **F7** — Specify how the session knows the overlay flag (import `isPerfOverlayEnabled`, an `enabled` parameter, or an App-level no-ping assertion) for AC-22.
8. **F8** — Add a test seam for escaped label values (`createMetrics` definitions override or an exported render/escape helper) or remove the escape clause from AC-6.
