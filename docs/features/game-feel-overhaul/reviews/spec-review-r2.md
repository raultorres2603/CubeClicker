# Spec Review — r2

## Summary

❌ **Changes requested — 2 MAJOR, 8 MINOR.** The r2 revision genuinely fixes the r1 blocking themes: AC-18 is now inset-only with no `filter`/outer shadow on the clipped rule; AC-15 measures per-frame `workMs` (not rAF intervals); the ledger explicitly releases `theme.ts`, `game/**`/`session.ts` and supersedes `reference-image-game-view` AC-8; the reveal is `role="group" aria-live="off"`; the scrim is gone and the toggle is at z-index 21 above the reveal at 20; the 8-ray flourish, `RevealUiPhase`/`RevealStagePhase` mapping, desktop spotlight overrides, `Crew` heading, minimized/pre-welcome contracts, workspace-manifest gates, invalid-input sanitization, `handleStatus` engine publish and documentation replacements are all present and testable. The rest are minor consistency/testability refinements.
