# Spec Review — r1

## Summary

❌ changes requested — The three deliverable clusters are fully covered (Terraform/AWS infra incl. WS passthrough, GitHub Actions gates, framework proof-of-working) and the framework contracts align with the existing state machine. But two gates that the spec pins as "green" provably cannot be green: every infra task's `terraform`/`actionlint` verify needs binaries that do not exist on the build host (no provisioning path designed, and the builder denies `curl`/`wget`), and the pinned smoke gate is structurally red (9/12 FAIL verified by running it; Mailpit is never started by the one-shot `compose run`). Seven MAJORs follow: an unpinned builder-permission surface for `infra/**`/`.github/**`, a deploy command chain that cannot execute as pinned, a staging contradiction, an unimplementable Q-4 default, a wrong idle-timeout inequality, ALB-unassertable health checks, and a docs pass that would leave falsified provider-neutrality statements on acceptance.
