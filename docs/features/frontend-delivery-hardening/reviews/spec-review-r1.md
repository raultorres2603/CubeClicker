# Spec Review — r1

## Summary
❌ changes requested — 1 MAJOR, 3 MINOR, 7 INFO. The core P-04/P-06 design is sound and the 11 ACs are mostly binary and complete. The initial graph becomes Three-free by moving the session's static `browser-env`/`render/scene`/`render/picking` imports behind a dynamically loaded `renderRuntime`, deferring `SpaceshipCustomizationPanel` behind a wrapper, and pinning `three` plus `react` as `manualChunks`; the fresh `bundle-report.json`/manifest gate is chained into `npm run build` (so the CI Build step and the Docker build stage fail on a violation); the nginx matrix keeps `index.html`/SPA fallback `no-cache` and only hashed `/assets/*` immutable; and the smoke-only `frontend-prod` service proves the real image. The existing `adaptive-render-budget-v2` attach/dispose evidence is preserved through an injected environment and the accepted gate-deferred path.

One MAJOR remains: **Q-4 silently changes the accepted `adaptive-render-budget-v2` Q-2 intro timing.** The accepted behavior starts the intro when the gate closes; this feature's async runtime load delays the attach, so the intro starts after the chunk load. Q-4 is not in the approval checkpoint (`spec.md:114`, `plan.md:258` include only Q-1/Q-2/Q-5/Q-6), and A-10 says the accepted adaptive behavior is "not re-opened" — a contradiction the spec does not resolve. The MINORs are the Q-9 CI auto-build/readiness gap, the tight audit-derived budget ceilings that only T3 can measure, and the stale summary byte counts.
