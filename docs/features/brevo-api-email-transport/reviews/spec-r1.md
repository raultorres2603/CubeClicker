# Spec Review — r1

## Summary

❌ **changes requested** — The diagnosis is sound (the SMTP `EAUTH` history is recorded in `registration-account-exists/build-log-T9.md`) and the Brevo HTTPS design matches the current provider contract (`POST https://api.brevo.com/v3/smtp/email`, `api-key` header, `sender`/`to`/`subject`/`htmlContent`/`textContent`, `201`/`202`, `GET https://api.brevo.com/v3/account`). The 11-validated / 9-synced / 6-production counts, the `smtp` runtime default, the guard ordering, the template reuse and the existing 502/token contract all check out against the repository.

Four MAJOR findings block approval: the documentation acceptance criteria can pass with the current "deployed uses SMTP" claims still present; the README API recovery/CLI/rotation and catalog-classification clauses are not pinned; the specification falsely states that `registration-account-exists` AC-11(a) remains met although T9 records Phase A as post-merge; and the build-log PII/token/username guards are incomplete across the task chain.

## Notes / backlog (non-blocking)

- The Brevo contract was independently checked against current developers.brevo.com pages: `POST /v3/smtp/email` accepts `sender`/`to`/`subject`/`htmlContent`/`textContent`, requires the `api-key` header, returns `201` for sent mail and `202` for scheduled mail; `GET /v3/account` uses the same `api-key` header. The spec's request shape and `201`/`202` treatment are correct.
- The 11/9/6 counts and catalog order match the current `render-env.ts` (7 SMTP + 2 new + 2 wiring) and the current production placeholder set plus `BREVO_API_KEY`.
- The guard precedence (catalog → email transport → SMTP port), the `smtp` runtime default, the explicit-`smtp` acceptance for every `NODE_ENV`, the fixed 10-second API timeout, the no-response-body rule and the token-invalidation-on-failure path all fit the existing code and the accepted contracts.
- The `docs/architecture/email.md` file does not exist today; the spec correctly records it as new and as the canonical transport reference.
