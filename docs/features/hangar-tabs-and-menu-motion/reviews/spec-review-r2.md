# Spec Review — r2 (hangar-tabs-and-menu-motion)

## Summary

✅ **Approved — 0 BLOCKER, 0 MAJOR, 3 MINOR, 3 INFO.** The r2 revision fixes every r1 finding (F1–F16) against the shipped source and the `544cce8` base. The four r1 BLOCKERs are gone: AC-1 is now a set-union plus per-tab catalog order with no concatenation claim; AC-5 pins the post-`normalizePartMap` bilateral counts (2/2/1, matching `parts-v2.ts:482-490` and `:521-543`); AC-12's geometry ban now agrees with the pinned `menu-rail` `height` / `menu-scan` `right` pseudo-element stops; AC-17 pins the `:not()`-scoped reduced-motion selectors in both existing blocks, the source order, and a specificity guard, and closes the pre-existing `reveal-spotlight` OS-preference gap (ledger AC-31 row). The four r1 MAJORs are also fixed: AC-10 pins both control-count fixtures (20 / 40), AC-2/AC-3 remove the dangling `aria-controls` and use one stable panel id with a resolvable `aria-labelledby`, every keyframe stop for all five keyframes is pinned, and the plan is rebased on `544cce8` with `App.tsx`/`App.test.tsx` untouched, the former App task deleted (5 tasks) and the session block extended rather than duplicated. All 29 ACs remain binary-testable, mapped to tasks, and the `{T1 ∥ T2} → T3 → T4 → T5` graph keeps exclusive `files_owned`. The spec is ready for the Q-1…Q-15 approval checkpoint; the six residual findings below are non-blocking.
