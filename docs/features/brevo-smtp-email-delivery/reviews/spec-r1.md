# Spec Review — r1

## Summary

❌ **changes requested** — The Brevo SMTP contract is accurate (verified against Brevo's docs: SMTP login + SMTP key, `smtp-relay.brevo.com:587` STARTTLS / `465` implicit TLS, SMTP key ≠ REST API key), and the Mailpit / plain-text / token-extraction path is genuinely preserved in the design. The blockers are: a tracked, modified `opencode.jsonc` has no mechanical secret protection; the CLI failure path and the credential audit can leak or miss a secret; T2 has no recorded asset source; the asset-serving and documentation ACs are not verifiable by the listed commands; and Q-9/Q-10/Q-6/Q-8 conflate user-owned and agent-decidable decisions.
