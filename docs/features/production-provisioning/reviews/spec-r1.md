# Spec Review — r1

## Summary

❌ **changes requested** — The spec is sound on naming, the 23-name catalog, the manual CI-preflighted deploy order, the provider/owner secret split and the owner-decision set, but it is built on a false Neon pre-state: the Neon `production` branch already exists as the project default (`br-floral-dream-zarerhtw`), while the spec plans to create it from a non-existent `main`, making T2/AC-2(b) unsatisfiable. The partial-failure cleanup would delete that pre-existing branch, the T8 credential audit fails on the current tree, the documentation inventory leaves stale production statements unpinned, and the Phase A owner hand-off has no task or gate. These are blocking.
